# 프리셋 4종

양식 파일이 없을 때 고르는 기본 서식이다. `python "${CLAUDE_PLUGIN_ROOT}/hwpx.py" presets`로 목록을 보고, `render`·`samples`·`fields`·`fill`의 양식 자리에 프리셋 이름을 쓴다. 각 프리셋 폴더(`presets/<이름>/preview.png`)에 첫 쪽 미리보기가 있다.

| 이름 | 제목 | 언제 | 글꼴 | 마크다운 단계 |
|---|---|---|---|---|
| `rnd-report` | 국가R&D 보고서형 | 연구 최종·중간·연차 보고서 | 함초롬바탕 11pt 본문, 표는 함초롬돋움 10pt | `#` 제1장 / `##` 1.1. / `###` 1.1.1. / `####` 1) / □○-· / 본문 |
| `gov-brief` | 공문서·개조식 보고형 | 기관 내부 보고·계획서 | 휴먼명조 15pt 글머리, 맑은 고딕 제목 | `#` Ⅰ. 개요 / `##` 1. 추진 배경 / □ 15pt, ○ 15pt, - 13pt, · 13pt (본문도 □·○로 씀) |
| `paper` | 학술 논문형 | 학회지·학위논문 형식 | 함초롬바탕 10pt, 첫 줄 들여쓰기 | `#` 1. 서론 / `##` 1.1. 소절 / 본문 / ○ - |
| `progress` | 월간·진도 보고형 | 월간업무보고서 같은 표 양식 | 맑은 고딕 | 표 칸을 `fill` 지시문으로 채움 (표1 표지, 표2 공정률, 표3 실적·계획, 표4 별첨) |

번호 형식: `rnd-report`는 `[표 1-1]`·`[그림 1-1]`(장별), `gov-brief`·`paper`는 `[표 1]`·`[그림 1]`, 수식은 모두 `(1)`.

## 기관 양식이 따로 있으면

기관이 준 양식 파일(.hwp/.hwpx)을 쓰는 것이 언제나 우선이다. 양식에 견본이 없는 역할(예: 그림)이 있으면 엔진이 기본 골격을 쓰고 `samples`에 '견본 없음'으로 알려 준다. 그런 역할은 견본이 있는 비슷한 프리셋을 참고해 직접 양식에 한 번 넣어 두면 다음부터 그 서식을 쓴다.
