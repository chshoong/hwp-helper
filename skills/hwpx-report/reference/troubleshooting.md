# 문제 해결

| 증상 | 원인 | 할 일 |
|---|---|---|
| `No module named 'lxml'` 또는 `'PIL'` | 파이썬 부품 없음 | 사용자에게 묻고 `python -m pip install --user lxml Pillow` |
| "한글(한컴오피스)이 설치된 Windows에서만 할 수 있는 작업이에요" | 한글 없음(Mac, 리눅스, claude.ai) | 기본 모드로 진행: .hwpx만 만들고, 미리보기·.hwp 변환은 생략, 수식 크기는 추정. 사용자에게 한글에서 열어 확인해 달라고 안내 |
| "구형 한글(.hwp) 파일은 한글이 설치된 PC에서만…" | 한글 없이 .hwp를 받음 | 사용자에게 한글에서 '다른 이름으로 저장 → HWPX 문서'로 바꿔 달라고 요청 |
| "한글이 N초 안에 응답하지 않아 작업을 멈췄어요" | 한글 안에 확인 창(보안 승인, 글꼴 대체, 복구 안내)이 떠 있음 | 사용자에게 한글을 한 번 직접 열어 창을 닫고(보안 승인은 '모두 허용') 다시 시도하자고 안내. 엔진이 띄운 한글은 자동으로 닫힌다 |
| "The RPC server is unavailable" | 한글이 막 닫히는 중에 다시 부름 | 엔진이 한 번 다시 시도한다. 계속되면 잠시 뒤 다시 |
| "한글이 파일을 열지 못했어요" | 파일 손상, 다른 프로그램에서 열림 | 사용자가 그 파일을 한글에서 닫았는지 확인 |
| "원본 파일을 덮어쓸 수 없어요" | 결과 경로가 원본과 같음 | 다른 이름(`_작성.hwpx`)으로 |
| `[오류] … 정의되어 있지 않아요` 로 저장 안 함 | 서식 참조가 깨짐(엔진 버그 가능) | 내용을 줄여 다시 시도해 원인 문단을 찾고, 사용자에게 알림 |
| 미리보기에 글자 겹침 | 한글 없이 추정한 수식 크기, 또는 아주 긴 그림 | 한글이 있으면 `equations` 명령으로 다시 계산. 그림은 `width=`를 줄임 |
| 글꼴이 다르게 보임 | 그 PC에 양식 글꼴(휴먼명조 등)이 없음 | 한글 기본 글꼴만 쓰는 프리셋을 고르거나, 사용자 PC에서 열면 정상이라고 안내 |
| `@칸` "여러 칸이 맞아요" | 머리 글자가 여러 칸에 들어맞음 | `fields`가 준 주소를 그대로 쓰거나 `#행 | #열` 번호로 |
| `@바꾸기` "찾지 못했어요" | 글자가 서식 경계로 나뉘어 있음 | 그 칸·문단을 `@칸`이나 `render --replace`로 다시 씀 |
| 한글 외 뷰어(한컴독스 등)에서 줄 배치가 다름 | 엔진은 줄 배치를 한글이 다시 계산하게 둠 | 한글에서 한 번 열어 저장하면 맞춰진다 |
| 경로가 아주 긴 파일(260자 넘음) | 한글의 경로 길이 제한 | 엔진이 짧은 임시 폴더로 복사해 처리하므로 그대로 써도 된다 |
