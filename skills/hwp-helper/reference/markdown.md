# 보고서 마크다운 문법

한 줄이 한 문단이다. 빈 줄은 무시한다(문단 사이 간격은 양식 서식이 정한다). `<!-- 메모 -->` 줄은 문서에 들어가지 않는다.

## 제목과 글머리

| 쓰는 법 | 뜻 | 예 |
|---|---|---|
| `# …` | 장 (1단계) | `# 제1장 서론`, `# Ⅰ. 개요`, 논문형 `# 1. 서론` |
| `## …` | 절 (2단계) | `## 1.1. 연구 배경`, 공문서형 `## 1. 추진 배경` |
| `### …` / `#### …` / `##### …` | 3~5단계 | `### 1.1.1. 세부`, `#### 1) 항목`, `##### 가. 세목` |
| `□ 글` `○ 글` `- 글` `· 글` | 개조식 1~4단계 | 기호 뒤에 공백 필수 (`-5%`는 일반 글) |
| `* 글` `※ 글` | 주석 (양식의 주석 서식, 보통 작은 글씨) | `* 출처: 통계청(2024)`, `※ 수치는 잠정값` — 기호 뒤 공백 필수(`*기울임*`은 꾸밈) |
| 그 밖의 줄 | 본문 | |

- 번호(제1장, 1.1. …)는 글에 직접 쓴다. 단계와 번호 형식은 `samples` 결과의 견본을 따른다.
- 양식이 글머리를 자동 글머리로 쓰면 기호는 글자로 들어가지 않고 양식의 기호가 붙는다(엔진이 처리).

## 글자 꾸밈

- `**굵게**`, `*기울임*` (단어 속 별표 `2*3*4`는 그대로 글자)
- `[[색:파랑]]파란 글[[/색]]` — 색 이름: 파랑, 빨강, 검정, 초록, 회색, 또는 `#1F3864`처럼 16진수
- 문단 속 수식 `$\hat{\beta}$` → `reference/equations.md`

## 표

```
표: 방법별 특성 비교 {#tbl:compare widths=2,3,3}
| 구분 | 장점 | 한계 |
|---|---|---|
| 방법 A | 단순함 | 셀 구성에 좌우 |
| 방법 B | 연속형 변수 활용 | ^^ |
| 요약 | 상황에 맞게 선택 | << |
```

- `표: 제목`은 표 바로 윗줄. 제목은 표에 붙은 **한글 캡션**(표 위)으로 들어간다. 번호는 양식 형식대로 붙는데, `[표 1]`처럼 장 번호가 없으면 한글 자동 번호(한글에서 표를 끼워 넣으면 알아서 바뀜), `[표 1-1]`처럼 장별이면 글자 번호다. 제목 없는 표도 된다.
- 양식에 데이터 표 견본이 없으면(표지·작성 요령 상자만 있으면) 기본 표를 쓴다: 실선, 머리 행 연한 음영·굵게, 칸 가운데 정렬, 10pt 이하.
- `{#tbl:이름}` 이름표 → 본문에서 `[@tbl:이름]`이라고 쓰면 "[표 1-1]"로 바뀐다.
- `widths=2,3,3` 열 너비 비율(열 수와 같아야 함). 없으면 글자 길이로 정한다.
- 병합: `^^` 위 칸과 합침, `<<` 왼쪽 칸과 합침. 합친 영역은 직사각형이어야 하고, 첫 행에는 `^^`, 첫 열에는 `<<`를 못 쓴다.
- 칸 안 줄바꿈: `첫 줄<br>둘째 줄`. 칸 안에도 `**굵게**`, `$수식$`을 쓸 수 있다.
- 첫 행은 머리 행(양식의 머리 칸 서식)으로 들어간다.

## 그림

```
![매칭 절차 흐름도](figs/flow.png){#fig:flow width=70%}
```

- 경로는 마크다운 파일이 있는 폴더 기준. PNG·JPG는 그대로, BMP 등은 PNG로 바꿔 넣는다.
- `width=70%` 본문 폭 대비(최대 100%). 원본 비율 유지, 쪽 높이를 넘지 않게 줄인다.
- 제목은 그림에 붙은 한글 캡션(그림 아래)으로 들어간다. 번호는 표와 같은 규칙(`[그림 1]`은 한글 자동 번호). 본문에서 `[@fig:flow]`.

## 번호 붙은 문단 수식

```
$$ \hat{\beta} = (X^T X)^{-1} X^T y $$ {#eq:ols}
```

- 한 줄에 수식만 쓴다(설명 글은 다음 줄). 여러 줄은 `$$` 줄로 열고 닫는다.
- 번호 `(1)`은 양식 형식대로 오른쪽에 붙는다. 본문에서 `[@eq:ols]` → "(1)".

## 번호와 참조

표·그림·수식 번호는 문서 전체를 먼저 훑어 매기므로 뒤에 나오는 것도 앞에서 참조할 수 있다. `--mode append`나 `--replace`로 나눠 넣었다면 마지막에 `renumber`로 다시 매긴다.
