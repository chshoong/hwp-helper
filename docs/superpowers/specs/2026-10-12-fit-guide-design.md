# 분량 맞추기(pages)와 작성 요령 체크리스트(guide) 설계

## 1. 목적

- **분량 맞추기:** "10쪽 이내" 같은 제한에 맞게, 한글로 실제 쪽수를 장별로 재고 Claude가 글을 줄이거나(넘칠 때) 보충해서(모자랄 때) 맞춘다. 양식 서식(글꼴·줄 간격·여백)은 바꾸지 않는다.
- **작성 요령 체크리스트:** 양식의 작성 요령·안내·배점을 장별 항목으로 뽑고, Claude가 다 쓴 보고서가 항목마다 답했는지(답함/약함/빠짐) 판단해 보여 주고 빠진 것을 채울지 묻는다.

## 2. 결정 (2026-10-12 사용자와 정함)

- 분량은 글을 줄여서 맞춘다. 서식은 건드리지 않는다. 지울 내용은 미리 보여 주고 확인받는다.
- 엔진은 잰다(쪽수, 제한, 배점, 작성 요령 항목). 판단과 고쳐 쓰기는 Claude가 하고, 적용은 기존 `render --replace`로 한다.

## 3. 쪽수 재기 (`pages`)

### 명령

`hwpx.py pages <문서.hwpx|.hwp> [--limit N] [--level 2] [--json]` — 한글 필요.

출력(글):
```
전체 12쪽 (제한 10쪽 이내 → 2쪽 넘음)
제1장 서론〔10점〕            1~2쪽 (2쪽)
제2장 데이터 분석〔30점〕      3~7쪽 (5쪽)
제3장 활용방안〔30점〕         8~12쪽 (5쪽)
```

`--json`: `{"pages": 12, "limit": {"pages": 10, "kind": "이내", "text": "10쪽 이내"} | null, "limits": [...], "sections": [{"title", "level", "score": 30 | null, "para": i, "start": 3, "end": 7, "count": 5}]}`.

### 한글 연동

- `bridge_hwp.ps1`에 동작 `pagemap`을 더한다. 숨은 한글로 열고, 본문(list 0)의 문단 번호 0부터 차례로 `SetPos(0, i, 0)`이 성공하는 동안 `KeyIndicator`로 쪽 번호를 얻어 `pages: [p0, p1, …]`과 `total = PageCount`를 낸다.
- `KeyIndicator`는 C# `Add-Type` 리플렉션(ParameterModifier 8개, 7번째 인자 short, 3번째 값이 쪽)으로 부른다(2026-10-08 실험으로 확인).
- 문서는 열기만 하고 저장하지 않는다.
- `bridge.page_map(path) -> tuple[int, list[int]]` (전체 쪽, 최상위 문단별 쪽). 문단 수가 엔진이 센 최상위 문단 수와 다르면 경고하고 적은 쪽에 맞춘다.

### 장 범위

- 장·절 제목: `samples.classify` 역할이 h1..h{level}인 최상위 문단(첫 구역).
- 각 제목의 시작 쪽 = 그 문단의 쪽. 끝 쪽 = 다음 같은 단계 이상 제목 시작 쪽 − 1(같은 쪽에서 시작하면 같은 쪽), 마지막은 전체 쪽.
- 제목이 없으면 `sections`는 빈 목록이고 전체 쪽수만 낸다.

### 분량 제한 찾기

- 문서 모든 문단 글(표 칸 포함)에서 `(?<!제)(\d{1,3})\s*(쪽|페이지|매|장)\s*(이내|이하|내외|까지|以內)` 를 찾는다. "A4 5매 내외"도 잡힌다.
- 여러 개면 `limits`에 모두 담고, `limit`은 `--limit`이 있으면 그것, 없으면 하나일 때만 그것(여럿이면 null — Claude가 묻는다).
- `--limit N`은 `{"pages": N, "kind": "이내", "text": "--limit"}`.

### 배점

- 제목 글 끝의 `[〔(\[]\s*(\d{1,3})\s*점\s*[〕)\]]` → `score`.

## 4. 작성 요령 뽑기 (`guide`)

### 명령

`hwpx.py guide <양식.hwpx|.hwp> [--json]`

출력(글): 장별로
```
제2장 데이터 분석〔30점〕
  - [요령] 데이터 전처리 과정과 이상치 처리 기준을 구체적으로 기술
  - [안내] ※ 표·그림을 활용하여 작성
분량: 10쪽 이내
```

`--json`: `{"limits": [...], "sections": [{"title", "score", "items": [{"kind": "요령"|"안내"|"배점", "text"}]}], "orphans": [...]}` — 첫 제목 앞의 항목은 `sections`의 `title: "(앞부분)"`에 담는다.

### 항목

- **요령:** 작성 요령 상자의 줄. 상자 = 최상위 문단의 표 가운데 다음 중 하나.
  - 칸이 1개인 표, 또는 첫 칸 글이 `작성\s*(요령|방법|안내)|유의\s*사항|기재\s*요령`이다.
  - 상자 안의 문단마다(머리 줄 "작성 요령" 자체와 빈 줄 제외) 한 항목이다.
  - 글머리 기호(-·○·※ 등)는 떼지 않는다.
- **안내:** 상자 밖 문단 중 `review._GUIDE_RE`에 맞거나, `^※`로 시작하면서 `작성|기술|기재|포함|제시|첨부|명시`가 든 문단이다.
- **배점:** 제목의 배점(3장과 같은 규칙) — `{"kind": "배점", "text": "30점"}`.
- 같은 글은 한 번만 넣는다. 어느 장인지는 그 문단(또는 상자 표) 앞의 가장 가까운 h1..h2 제목으로 정한다.
- 항목이 하나도 없으면 "양식에서 작성 요령을 찾지 못했어요"를 출력하고 `sections`는 빈 목록이다.

### 판단 (Claude, 스킬 안내)

- `guide`를 원본 양식에 실행한다(다 쓴 문서에는 안내가 지워져 있음). 원본이 없으면 다 쓴 문서에 실행하고 "남은 안내만 봤어요"라고 알린다.
- 다 쓴 보고서는 `read`로 읽는다. 항목마다 근거 문장을 들어 답함/약함/빠짐을 표로 보여 준다.
- 빠짐·약함은 "채워 드릴까요?"라고 묻는다. 채울 때는 그 장만 `read --anchors` → `render --replace`. 원문에 없는 수치·사실은 쓰지 않는다.

## 5. 분량 맞추기 흐름 (스킬 안내, `reference/fit.md`)

1. `pages`로 잰다. 제한이 없거나 여럿이면 사용자에게 묻는다.
2. 넘친 쪽수를 장마다 나눈다. 배점이 있으면 "쪽수 ÷ 배점"이 큰 장부터, 없으면 쪽수가 많은 장부터 줄인다. 장마다 "줄일 쪽수"를 정해 보여 준다.
3. 장마다 `read --anchors`로 읽고 줄일 곳을 고른다.
   - 줄이는 방법: 겹치는 설명 합치기, 군더더기·반복 빼기, 긴 문장 나누기, 개조식 다듬기.
   - 지키는 것: 수치·고유명사·배점 항목에 답하는 문장·표·그림·캡션(표·그림을 줄여야 하면 따로 묻는다).
   - "빼는 문장 / 합치는 문장"을 사용자에게 보여 주고 확인받는다.
4. 확인받은 장만 `render <문서> <새.md> <새 결과> --replace a:b`로 바꾼다. 원본은 덮어쓰지 않는다.
5. 다시 `pages`로 잰다. 제한 안이면 끝. 최대 3번까지 되풀이한다. 그래도 넘치면 멈추고, 남은 쪽수와 다음 후보를 보여 준다.
6. 모자라면 반대로 배점 큰 장부터 보충한다. 원문·사용자 자료에 없는 수치·사실은 쓰지 않고, 필요한 자료를 묻는다.

## 6. 오류 처리

| 상황 | 동작 |
|---|---|
| 한글 없음 (`pages`) | "한글이 있어야 쪽수를 잴 수 있어요"로 멈춤(종료 코드 2) |
| 장·절 제목 없음 | 전체 쪽수만 |
| 제한 없음·여럿, `--limit` 없음 | 쪽수만 내고 `limit: null`(글 출력에 "제한이 몇 쪽인가요?") |
| 작성 요령 없음 | 안내 문구 출력, 종료 코드 0 |
| 한글 문단 수와 엔진 문단 수가 다름 | 경고, 적은 쪽에 맞춤 |

## 7. 범위 밖

- 서식(글꼴 크기·줄 간격·여백·빈 줄) 조정으로 쪽수 맞추기.
- 장별 쪽수 제한("제2장 3쪽 이내")의 자동 판정 — 제한 목록에는 나오고 Claude가 읽어서 쓴다.
- 둘째 구역 이후.

## 8. 시험

- 단위:
  - `find_limits`("10쪽 이내", "15페이지 이하", "A4 5매 내외", "제3장"은 제외, 여러 개).
  - `heading_score`(〔30점〕, (15점), [5점]).
  - `sections_from_pages`(문단별 쪽 → 장 범위, 같은 쪽 시작, 마지막 장, 제목 없음).
  - `guide_items`(1칸 상자, "작성 요령" 머리 표, ※ 안내 줄, 배점, 장 배정, 중복 제거, 앞부분, 항목 없음).
- CLI: `pages`를 가짜 `bridge.page_map`으로(글·JSON 출력, 한글 없음 오류), `guide` 글·JSON.
- 한글(hangul): `---쪽---`으로 3쪽 문서 → `page_map` 결과로 장 시작 쪽 1·2·3.
- 수동: 일부러 길게 쓴 보고서를 흐름대로 줄여 제한 안에 드는지(쪽 그림 확인, ledger 기록).
