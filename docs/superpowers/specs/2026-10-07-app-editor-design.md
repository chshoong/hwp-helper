# 앱 안 한글 편집 화면 (edit) 설계

## 1. 목적

Claude 데스크톱 앱 안의 브라우저 창에서 한글(HWPX) 문서를 문서처럼 보면서

- 문단·표 칸의 글을 **직접 고치고**,
- "여기 두 줄로 줄여줘" 같은 **부탁을 남겨 Claude가 양식 서식 그대로 반영**하게 한다.

고친 내용은 원본이 아니라 **파일 사본**(`원본_수정.hwpx`)에 반영한다. 한글이 없어도 보고 고칠 수 있고, 한글이 있으면 실제 쪽 모양도 확인할 수 있다.

## 2. 배경과 결정

- 한글 창 자체를 Claude 앱 안에 띄울 수는 없다. 대신 앱의 브라우저 창(preview)에 로컬 편집 화면을 띄운다.
- claude.ai 아티팩트 방식은 문서가 PC 밖으로 나가고 직접 고친 글이 바로 반영되지 않아 고르지 않았다(2026-10-07 사용자 선택: 로컬 방식).
- 화면은 실제 쪽 그림 위에서가 아니라 **문서처럼 흉내 낸 HTML 화면**에서 바로 고친다. 쪽 나눔이 정확하지 않으므로 [쪽 모양 확인]으로 한글이 그린 실제 쪽 그림을 따로 본다(사용자 선택: 나안).
- 부탁 반영은 이미 있는 엔진 기능 `render_into(replace=(시작, 끝))`(문단 범위를 새 마크다운으로 바꾸기, 견본 서식 복제)을 쓴다.

## 3. 사용 흐름

1. 사용자: "이 파일 앱에서 고칠래" → Claude가 `hwpx.py edit start <원본.hwpx>` 실행.
2. 원본 옆에 `원본_수정.hwpx` 사본을 만든다(이미 있으면 이어서 쓴다). 원본은 읽기만 한다.
3. 127.0.0.1의 빈 포트로 서버를 띄우고 `http://127.0.0.1:<포트>/?k=<열쇠값>` 주소를 출력한다. Claude가 그 주소를 앱 브라우저 창으로 연다.
4. 사용자가 문단을 누르면 [고치기]·[부탁하기]가 나온다.
   - 고치기: 글을 고쳐 저장 → 서버가 즉시 사본에 반영.
   - 부탁하기: 부탁 글을 쓰면 대기 목록에 쌓인다.
5. Claude는 부탁 파일을 지켜보다(Monitor) 새 부탁이 오면 그 범위를 읽고 새로 써서 서버를 통해 반영한다. 화면은 저절로 새로 고쳐지고 부탁은 "반영됨"이 된다.
6. 대화가 없을 때 남긴 부탁은 쌓여 있다가 "부탁 반영해줘"라고 하면 한꺼번에 처리한다.
7. 끝나면 사용자가 사본을 한글로 열어 확인·제출한다.

## 4. 구성

```
hwpxkit/editor/
  __init__.py
  doc.py      문서 모델: 사본 읽기 → 화면용 블록 목록, 문단·칸 글 바꾸기, 판 번호, 이력(되돌리기)
  queue.py    부탁 대기 목록 (JSONL 파일 읽기·쓰기·상태 바꾸기)
  server.py   http.server 기반 로컬 서버 (열쇠값 확인, 한 곳에서만 쓰기, 유휴 종료)
  page.html   화면 (HTML 하나, 외부 자원 없음)
```

새 의존성은 없다(파이썬 표준 라이브러리 + 기존 lxml).

### 파일 배치 (원본이 `보고서.hwpx`일 때)

| 파일 | 내용 |
|---|---|
| `보고서_수정.hwpx` | 고친 내용이 들어가는 사본 |
| `보고서_수정.부탁.jsonl` | 부탁 대기 목록 (한 줄에 하나) |
| `보고서_수정.이력/` | 저장 직전 사본들 (최근 50단계, 되돌리기·되살리기용) |
| `보고서_수정.서버.json` | 실행 중 서버의 포트·열쇠값·PID (CLI가 서버를 찾는 데 씀) |

### 화면용 블록 (서버 → 화면)

`GET /api/doc` →

```json
{"version": 7, "name": "보고서_수정.hwpx", "external_change": false,
 "blocks": [
   {"i": 3, "kind": "para", "role": "h1", "text": "□ 제1장. 데이터 이해",
    "size": 16, "bold": true, "indent": 0, "mixed": false},
   {"i": 4, "kind": "para", "role": "bullet1", "text": " ◦ (분석 대상) …", "size": 15, "bold": false, "indent": 10},
   {"i": 5, "kind": "table", "rows": [[{"r":0,"c":0,"text":"창고","rs":1,"cs":1}, …]]}
 ]}
```

- `i`는 최상위 문단 번호로 `reader --anchors`, `render --replace a:b`와 같은 번호다. 표는 표를 담은 최상위 문단 번호.
- `role`은 `samples.classify` 결과(h1~h5, bullet1~, note, body, blank, caption 등).
- `size`·`bold`·`indent`는 문단 첫 글자 모양·문단 모양에서 읽어 화면을 흉내 내는 데만 쓴다.
- `mixed`는 문단 안에 글자 모양이 둘 이상 섞였는지(고치면 하나로 합쳐짐을 알리기 위해).
- 첫 구역만 다룬다. 구역이 여러 개면 첫 구역만 보여 주고 화면 위에 알린다.

### 서버 API

모든 요청은 `k`(열쇠값)가 맞아야 한다(쿼리 또는 `X-Key` 헤더). 틀리면 403.

| 요청 | 하는 일 |
|---|---|
| `GET /` | page.html |
| `GET /api/doc` | 화면용 블록 (위) |
| `POST /api/edit` `{version, i, text}` 또는 `{version, i, r, c, text}` | 문단 하나 또는 표 칸 하나의 글을 바꾼다. 첫 글자 모양 유지. 판 번호가 다르면 409 |
| `POST /api/ask` `{version, start, end, text}` | 부탁을 대기 목록에 넣는다(범위 글과 판 번호 함께 기록) |
| `GET /api/asks` | 부탁 목록과 상태 |
| `POST /api/apply` `{id, md}` | (Claude 전용, CLI가 부름) 부탁 범위를 새 마크다운으로 바꾼다 |
| `POST /api/undo` | 한 단계 되돌리기 |
| `POST /api/pages` | (한글 있을 때) 사본의 쪽 그림을 만들어 주소 목록을 돌려준다 |
| `GET /pages/<n>.png` | 쪽 그림 |

### CLI (`hwpx.py edit …`)

| 명령 | 하는 일 |
|---|---|
| `edit start <원본.hwpx>` | 사본 준비, 서버 시작(백그라운드), 주소 출력. 이미 실행 중이면 그 주소를 출력 |
| `edit asks <원본.hwpx> [--json]` | 대기 중 부탁 목록 (범위, 부탁 글, 그 범위의 현재 마크다운) |
| `edit apply <원본.hwpx> <id> <새내용.md>` | 부탁 반영 (서버의 `/api/apply` 호출) |
| `edit stop <원본.hwpx>` | 서버 끄기 |

`asks --json`이 주는 범위 마크다운은 `reader.to_markdown`과 같은 형식이라, Claude는 기존 쓰기 규칙대로 새 내용을 쓴다.

## 5. 동작 규칙

### 문단·칸 글 바꾸기

- 문단의 글자 줄(`hp:run`)들을 첫 줄 하나로 합치고 그 글자 모양(`charPrIDRef`)을 쓴다. 문단 모양·스타일은 그대로.
- 글머리 문단은 양식의 앞 공백·기호(ParaStyle.lead)를 사용자가 지워도 다시 붙이지 않는다(보이는 그대로 저장). 화면은 기호를 포함한 글을 보여 준다.
- 고친 글에 줄바꿈이 있으면 거절하고 "여러 문단은 부탁하기로" 안내한다(문단 나누기는 서식 판단이 필요).
- 문단 안에 표·그림 같은 개체가 있으면 글만 바꾸고 개체는 그대로 둔다. 개체만 있는 문단은 고치기를 막는다.
- 0번 문단(쪽 설정)은 글만 바꾼다(구역 설정 개체 유지).

### 판 번호와 동시 수정

- 사본에 쓸 때마다 판 번호가 1씩 오른다. 쓰기는 서버 안의 잠금 하나로 차례대로 한다.
- 화면의 고치기는 자기가 본 판 번호를 함께 보낸다. 다르면 409 → 화면이 "그 사이 문서가 바뀌었어요" 알리고 새로 불러온다(입력한 글은 상자에 남긴다).
- 부탁에는 남길 때의 판 번호와 범위의 글(문단별)을 적는다. 반영할 때:
  1. 현재 문서에서 그 범위 글이 같은 번호에 그대로 있으면 반영.
  2. 번호가 밀렸으면 같은 글이 이어진 자리를 찾아 반영(한 곳일 때만).
  3. 못 찾으면 바꾸지 않고 부탁 상태를 `stale`로 → Claude가 사용자에게 다시 확인.

### 이력과 되돌리기

- 쓰기 전 사본을 `이력/<판번호>.hwpx`로 복사한다. 50개를 넘으면 오래된 것부터 지운다.
- 되돌리기는 가장 최근 이력 파일로 사본을 바꾸고 판 번호를 올린다(되돌리기도 한 번의 쓰기). 반영된 부탁의 상태는 되돌리지 않는다.

### 외부 변경

- 서버는 마지막으로 자기가 쓴 사본의 수정 시각·크기를 기억한다. `/api/doc` 때 달라졌으면 판 번호를 올리고 `external_change: true` → 화면이 "한글 등에서 바뀐 내용을 불러왔어요" 표시.
- 사본이 한글에서 열려 있어 쓰기가 실패하면(파일 잠김) 바꾸지 않고 "한글에서 이 사본을 닫은 뒤 다시 저장해 주세요"를 돌려준다.

### 보안과 수명

- 127.0.0.1에만 묶는다. 열쇠값은 `secrets.token_urlsafe(16)`.
- 마지막 요청 뒤 2시간이 지나거나 `edit stop`이면 끝난다. 끝날 때 `서버.json`을 지운다.
- `서버.json`의 PID가 살아 있지 않으면 `edit start`가 새로 띄운다.

### 쪽 모양 확인

- 한글이 있으면 기존 `bridge.page_images`로 사본의 쪽 그림을 만들어 화면 오른쪽 덮개 창에 보여 준다. 몇 초 걸리므로 진행 표시.
- 한글이 없으면 버튼을 누를 때 "한글이 있어야 실제 쪽 모양을 볼 수 있어요" 안내.

## 6. 화면 (page.html)

- 위쪽 막대: 파일 이름, 판 번호, [되돌리기], [쪽 모양 확인], 대기 부탁 수.
- 본문: 블록을 위에서 아래로 문서처럼 보여 준다. 글자 크기·굵기·들여쓰기를 흉내 내고(바탕 흰 종이, 가운데 정렬 폭 A4 비율), 표는 표로, 빈 문단은 빈 줄로.
- 문단을 누르면 테두리 강조와 작은 도구: [고치기] → 그 자리에서 글 상자로 바뀜(저장/취소), [부탁하기] → 부탁 글 상자. Shift+누르기로 여러 문단을 범위로 골라 부탁할 수 있다.
- 표 칸을 누르면 [고치기]만(칸 글). 표 전체 부탁은 표를 담은 문단을 골라서.
- 부탁이 걸린 문단 옆에 상태 표시(대기 중 / 반영됨 / 다시 확인 필요).
- 2초마다 `/api/doc`의 판 번호만 확인해 바뀌었으면 새로 그린다(고치는 중인 상자는 유지).
- 글자 모양이 섞인 문단을 고치려 하면 "굵게 등 섞인 모양이 하나로 합쳐져요" 확인.
- 외부 자원(글꼴, 스크립트)을 불러오지 않는다.

## 7. 오류 처리

| 상황 | 동작 |
|---|---|
| 원본이 .hwp | `edit start`가 기존 변환으로 사본을 .hwpx로 만든다(한글 필요). 한글이 없으면 "hwpx로 바꿔 주세요" |
| 열쇠값 틀림 | 403, 아무것도 안 함 |
| 판 번호 다름 | 409, 화면이 새로 불러오기 |
| 줄바꿈 포함 고치기 | 400, "여러 문단은 부탁하기로" |
| 사본 잠김 | 423, "한글에서 사본을 닫아 주세요" |
| 부탁 범위를 못 찾음 | 부탁 상태 stale, 문서 안 바꿈 |
| 반영 마크다운 렌더 실패 | 문서 안 바꿈, 부탁 상태 error와 메시지 |
| 포트 사용 중 | 다른 빈 포트 |

## 8. 범위 밖

- 표 행·열 추가·삭제, 셀 병합 같은 구조 편집, 그림 바꾸기, 글자 부분 서식(일부만 굵게) 편집 — 부탁으로 처리.
- 둘째 구역 이후 편집, 여러 사람 동시 편집, 링크 공유, 열린 한글 창과의 연동(live와 별개).

## 9. 시험

- `doc.py` 단위: 블록 만들기(역할·크기·표 칸), 문단 글 바꾸기 후 문단 모양·글자 모양 유지, 줄바꿈 거절, 개체 문단 보호, 이력 50개 유지, 되돌리기, 외부 변경 감지.
- `queue.py` 단위: 부탁 쌓기·상태 바꾸기, 범위 다시 찾기(그대로 / 밀림 / 못 찾음 → stale).
- `server.py` 통합: 임시 폴더에서 실제 서버를 띄워 HTTP로 — 열쇠값 403, 고치기 200·409, 부탁→`edit apply`→반영, 되돌리기, 잠긴 사본 423, 유휴 종료(시간 줄여서).
- CLI: `edit start`가 원본을 건드리지 않음(해시 비교), 이미 실행 중이면 같은 주소.
- 한글 필요(hangul 표시): 쪽 모양 확인이 그림을 돌려줌.
- 화면: 앱 브라우저 창에서 실제로 열어 문단 고치기·부탁하기·되돌리기를 한 번씩 확인(수동 확인 기록).
